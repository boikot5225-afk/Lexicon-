# Lexicon

Автономное Android-приложение для изучения слов с контекстом.

Главный сценарий: ИИ создаёт карточки, пользователь вставляет их в Lexicon, приложение сохраняет, озвучивает и повторяет.

## Импорт
Одна строка = одна карточка; ровно пять полей, разделённых вертикальной чертой:
слово | транскрипция | перевод | пример | перевод примера

Пример:
终于 | zhōngyú | наконец | 他终于回来了。 | Он наконец вернулся.
考虑 | kǎolǜ | обдумывать | 我需要考虑一下。 | Мне нужно подумать.

Транскрипцию можно оставить пустой. Внутри полей знак | использовать нельзя. Приложение показывает ошибки до импорта, корректные строки сохраняет, совпадающие карточки пропускает.

Промпт для ChatGPT или Claude: «Создай карточки для изучения слов. Каждая строка содержит ровно пять полей: слово | транскрипция | перевод | предложение с этим словом | перевод предложения. Без заголовков, Markdown, нумерации и вертикальных черт внутри полей».

## Реализованное
- Kotlin, Jetpack Compose, Room;
- локальный словарь по пяти языкам, просмотр контекстов, удаление;
- массовый импорт текста с предпросмотром и обработкой дубликатов;
- Android TTS: озвучка слова и предложения при наличии языкового голоса;
- простая интервальная тренировка «Помню / Не помню»;
- unit-тесты парсера и расписания, GitHub Actions для сборки APK.

## Сборка
JDK 17, Gradle 8.13, Android SDK 36.
Команда: gradle :app:testDebugUnitTest :app:assembleDebug
GitHub Actions публикует артефакт lexicon-debug-apk после успешной сборки.

## Текущее ограничение
Это первый прототип. Отдельных упражнений с вводом и диктанта, импорта файла и резервных копий ещё нет. Работа на реальном устройстве пока не подтверждена.
