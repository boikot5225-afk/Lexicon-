# Lexicon

Автономное Android-приложение для изучения слов с контекстом.

Главный сценарий: ИИ создаёт карточки, пользователь вставляет их в Lexicon, приложение сохраняет, озвучивает и повторяет.

## Импорт
Одна строка = одна карточка; ровно пять полей, разделённых вертикальной чертой:
слово | транскрипция | перевод | пример | перевод примера

Пример:
终于 | zhōngyú | наконец | 他终于回来了。 | Он наконец вернулся.
考虑 | kǎolǜ | обдумывать | 我需要考虑一下。 | Мне нужно подумать.

Транскрипцию можно оставить пустой. Внутри полей знак | использовать нельзя. Приложение показывает ошибки до импорта, корректные строки сохраняет, совпадающие карточки пропускает.

Промпт для ChatGPT или Claude: «Создай карточки для изучения слов. Каждая строка содержит ровно пять полей: слово | транскрипция | перевод | предложение с этим словом | перевод предложения. Без заголовков, Markdown, нумерации и вертикальных черт внутри полей».

## Реализованное
- Kotlin, Jetpack Compose, Room;
- локальный словарь по пяти языкам, просмотр контекстов, удаление;
- массовый импорт текста с предпросмотром и обработкой дубликатов;
- Android TTS: озвучка слова и предложения при наличии языкового голоса;
- простая интервальная тренировка «Помню / Не помню»;
- режим «Написать слово»: перевод → ввод → проверка написания → следующее повторение;
- отдельное расписание интервального повторения для узнавания и написания (успехи и ошибки в одном режиме не обнуляют другой);
- лимит 10 новых слов в день на каждый язык, общий для обоих режимов; запланированные повторения лимитом не блокируются;
- сохранение ранее изученных карточек и старой истории узнавания при обновлении базы Room с версии 1 на версию 2;
- подсказка с пропуском в предложении, если слово можно скрыть безошибочно; в противном случае исходное предложение показывается только после ответа;
- unit-тесты парсера и расписания, GitHub Actions для сборки APK.

## Настройки обучения

Для каждого языка независимо сохраняются лимит 5/10/20/30/50 новых слов в день,
режим автоозвучки (выключена/слово/пример/оба) и скорость произнесения (0.7–1.3×).
Плановые повторения старых слов лимитом не блокируются. В режиме письменного ответа
автоозвучка включается только после проверки написанного слова.

## Изучение, ошибки и контексты (0.5.0)

- «Уже знаю»: отложить новое слово на 30 дней в текущем режиме, не расходуя дневной лимит; другой режим остаётся независим.
- Ошибка возвращает слово через 10 минут, но теперь отступает максимум на две ступени успешных повторений, не обнуляя всю историю.
- Для одного слова можно хранить несколько пар «пример + перевод». Они показываются в словаре и чередуются в повторении. Их можно добавлять вручную.
- В импорте повторение слова и перевода с новым примером дополняет карточку, не обнуляя прогресс. Старый формат пяти полей остаётся.
- Room мигрирует базу 2→3, сохраняя все существующие слова и перенося старые примеры; цепочка 1→2→3 поддерживается.

## Новый интерфейс (0.6.0)

- Тёплая «бумажная» палитра (кремовый фон, графитовый текст, бирюзовый акцент), светлая и тёмная тема; изучаемые слова набраны системным шрифтом с засечками; иконки вместо символов.
- Главный экран «Сегодня»: сколько слов ждёт повторения (повторения и новые), запуск карточек или письма, новые слова за день, выученные слова, список трудных слов.
- Повторение во весь экран: прогресс сессии, крупное слово, слово подсвечено в примере, на кнопках видно, когда слово вернётся; в письме после проверки подчёркиваются неверные знаки.
- Словарь: компактные строки с шестью делениями прогресса, поиск также по транскрипции, фильтры «Новые / Трудные / Выучены», подробности слова в нижней панели.
- Импорт: кнопки «Скопировать промпт для ИИ» и «Вставить из буфера».
- Озвучка «Фраза» в карточках теперь произносит показанный пример, а не всегда первый.

## Резервная копия и редактирование (0.7.0)

- Настройки → «Резервная копия»: «Сохранить копию в файл» записывает все языки (слова, примеры, прогресс обоих режимов, настройки) в JSON через системный выбор файла; «Восстановить из файла» сначала проверяет файл целиком и показывает, сколько в нём слов, и только после подтверждения заменяет данные. Ошибка при восстановлении откатывает всё: данные не меняются.
- Словарь → слово → «Изменить»: правка слова, транскрипции и перевода без потери прогресса; совпадение с уже существующим словом не допускается.
- У каждого примера есть кнопка правки: изменить текст и перевод или удалить пример (последний пример слова удалить нельзя).

## Сборка
JDK 17, Gradle 8.13, Android SDK 36.
Команда: gradle :app:testDebugUnitTest :app:assembleDebug
GitHub Actions публикует артефакт lexicon-debug-apk после успешной сборки.

## Текущее ограничение
При первом ответе слово считается введённым в изучение; показ слова без оценки не расходует дневной лимит. Слова из старой базы, уже проходившие повторение, не становятся новыми при обновлении. Это первый прототип. Диктанта на слух и импорта карточек из файла ещё нет. При вводе слова проверяется написание самого словарного слова; варианты словоформ/синонимов автоматически не принимаются, но их можно засчитать вручную. Работа на реальном устройстве пока не подтверждена.

Ключ хранится отдельно и не публикуется в GitHub. До добавления Actions secrets
CI продолжает выпускать debug APK. Android не позволит установить release APK
поверх старой debug-сборки с другой подписью. Не удаляй текущую установку без
резервной копии данных.
