# Lexicon

Автономное Android-приложение для изучения слов с контекстом.

Главный сценарий: ИИ создаёт карточки, пользователь вставляет их в Lexicon, приложение сохраняет, озвучивает и повторяет.

## Импорт
Одна строка = одна карточка; ровно пять полей, разделённых вертикальной чертой:
слово | транскрипция | перевод | пример | перевод примера

Пример:
终于 | zhōngyú | наконец | 他终于回来了。 | Он наконец вернулся.
考虑 | kǎolǜ | обдумывать | 我需要考虑一下。 | Мне нужно подумать.

Транскрипцию можно оставить пустой. Внутри полей знак | использовать нельзя. Приложение показывает ошибки до импорта, корректные строки сохраняет, совпадающие карточки пропускает.

Промпт для ChatGPT или Claude: «Создай карточки для изучения слов. Каждая строка содержит ровно пять полей: слово | транскрипция | перевод | предложение с этим словом | перевод предложения. Без заголовков, Markdown, нумерации и вертикальных черт внутри полей».

## Реализованное
- Kotlin, Jetpack Compose, Room;
- локальный словарь по пяти языкам, просмотр контекстов, удаление;
- массовый импорт текста с предпросмотром и обработкой дубликатов;
- Android TTS: озвучка слова и предложения при наличии языкового голоса;
- простая интервальная тренировка «Помню / Не помню»;
- режим «Написать слово»: перевод → ввод → проверка написания → следующее повторение;
- отдельное расписание интервального повторения для узнавания и написания (успехи и ошибки в одном режиме не обнуляют другой);
- лимит 10 новых слов в день на каждый язык, общий для обоих режимов; запланированные повторения лимитом не блокируются;
- сохранение ранее изученных карточек и старой истории узнавания при обновлении базы Room с версии 1 на версию 2;
- подсказка с пропуском в предложении, если слово можно скрыть безошибочно; в противном случае исходное предложение показывается только после ответа;
- unit-тесты парсера и расписания, GitHub Actions для сборки APK.

## Сборка
JDK 17, Gradle 8.13, Android SDK 36.
Команда: gradle :app:testDebugUnitTest :app:assembleDebug
GitHub Actions публикует артефакт lexicon-debug-apk после успешной сборки.

## Текущее ограничение
При первом ответе слово считается введённым в изучение; показ слова без оценки не расходует дневной лимит. Слова из старой базы, уже проходившие повторение, не становятся новыми при обновлении. Это первый прототип. Диктанта на слух, импорта файла и резервных копий ещё нет. При вводе слова проверяется написание самого словарного слова; варианты словоформ/синонимов автоматически не принимаются, но их можно засчитать вручную. Работа на реальном устройстве пока не подтверждена.

Установлена адаптивная launcher-иконка (книга с закладкой).
Подписанная стабильным ключом release-сборка настраивается по [SIGNING.md](SIGNING.md).
Ключ хранится отдельно и не публикуется в GitHub. До добавления Actions secrets
CI продолжает выпускать debug APK. Android не позволит установить release APK
поверх старой debug-сборки с другой подписью. Не удаляй текущую установку без
резервной копии данных.
